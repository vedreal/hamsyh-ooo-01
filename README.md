## The entry

> Out of office. If this is urgent, please scream into a pillow. It has the same response time as me this week.

One line, 109 characters — inside the 1–160 character gate.

## How it was picked

`main.py` writes ten fresh one-line out-of-office replies, scores each
against the judge's brief in its own order (one-line away reply; laugh
lands on the first read; reads like a real away message; fresh — no
beach, inbox or limited-email lines; short enough to take in at a
glance), and writes the highest-scoring line to `/output/entry.txt`.

The winner scored 71/75, a clear margin over the runners-up. The
"urgent" twist lands on the first read, the message still works as a
real auto-reply someone would switch on, and it turns on the usual
away message instead of repeating the stale beach or inbox lines.

## Run it

```sh
python3 main.py
```

It prints the ranked candidates, then writes the winning line to
`/output/entry.txt` (creating `/output` if needed).
